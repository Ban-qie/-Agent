# V0 / v0.1.0

日期：2026-09-17。基于 Microsoft Data Formulator `0.8b1` / `5477f0e236426dc8f74a498ec400414fba7fbc0f`，保留上游历史与 MIT 许可。本次发布为本机受限电商分析源码基线，不发布上游同名包、桌面安装包或公网服务。

## 功能

三项固定电商指标、明确日期/地区/比较条件、单 AnalystAgent + Qwen Flash 工具反馈闭环、表格与柱状图、工作区保存与重启恢复；模型预算、请求幂等、固定只读 worker 和本机访问边界。数据及模型文本不直接作为可信业务数值。

- 实际 Edge → Flask → 单 AnalystAgent → Qwen → 固定 worker → 持久化 → 页面：4 个样例通过，独立原始 CSV + Decimal 参考一致。
