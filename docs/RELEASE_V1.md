# V1 / v0.2.0（本地固化）

日期：2026-09-18。以 V0 `v0.1.0` 为回退基线，沿用 Microsoft Data Formulator `0.8b1`、MIT 许可与上游历史。`v0.2.0` 表示项目第二个迭代的源码基线，不表示生产 1.0，也不修改上游包名/包版本。本阶段不推送远端、不创建 GitHub Release 或发布包。

## 变更

- 新增固定版本 LangGraph 状态图、角色/状态契约、保守中文条件规范化、澄清与父条件继承；七个业务节点目前都是确定性处理器，不调用模型。
- 显式 V1 受限路由与独立保存格式；前端支持父分支、独立分析、历史与刷新恢复，按已验证结果显示表格、柱状和趋势图。
- 完整受限分组后排序/Top N，两期差额排名和精确均价排序；未知/冲突条件需要澄清。终态不可重写，活跃任务 OS lease、真实退出中断恢复、重复请求幂等、失败部分结果保留。
- V0 默认和 Qwen 单 AnalystAgent 路径保留；运行时切回 `v0` 即可读取原 V0 工作区。

## 范围与限制

运行、条件边界、容量、时间限制和回退见 [ECOMMERCE_V1.md](ECOMMERCE_V1.md)。本版限 Windows 本机单用户与固定快照；没有自由问数、多模型角色推理、自动续跑、扩展经营指标、生产部署或多租户授权。

本地标签树不含私有阶段报告和交接文件；此前本地开发提交曾包含这些文档，移出当前树不会抹去历史。保留历史、不做重写，本阶段未将这些提交推送。未来如授权远端发布，应单独核对历史分发范围，不能把当前树扫描等同于整个历史可公开保证。
