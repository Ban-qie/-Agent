# V5 TODO：可选数据源、刷新与后台任务

**整个阶段可选。** 输入是 V4-26 已通过及一项明确的新需求。每卡只有在对应模块启用后才是必做；不能为了完整技术栈提前加 MySQL、调度器或 MCP。

## V5-01｜选择一个真实数据需求

- [ ] 输出 `docs/specs/V5-source-request.md`：谁提供数据、需要回答什么现有 Olist 不能回答的问题、合法访问方式、体量、刷新频率、币种/时区/许可。先选择受限 CSV、只读 MySQL 或第二数据集中的一种。
- 验收：没有明确需求则本阶段所有卡记 N/A 并在 V4 结束；不是“有 API 所以接入”。外部凭据缺失时可先做接口/fixture，不宣称连接完成。

## V5-02｜统一连接器契约

- [ ] 文件：优先审查已有 `data_loader/`、connector framework，拟新增 E 的受限 adapter。定义 discover/read/health、source_id/version、最大行/字节/耗时、取消、凭据引用和安全错误；不开放 write 或任意 SQL 方法。
- 验收：fake adapter 能模拟成功/权限拒绝/超时/模式变化；返回数据与控制指令分离；connector 不改变 Agent 工具权限。

## V5-03｜实现所选输入边界

- [ ] CSV：扩展名/真实格式/编码/最大行字节/列数/临时隔离/路径校验，拒绝压缩炸弹和路径穿越。MySQL：服务端只读账号、网络目标白名单、固定查询/参数化、只读事务、超时；DSN 不回显。只实施01选定分支。
- 验收：写操作权限在数据库层也被拒绝；SSRF/任意文件/不受限表不可访问；连接失败返回明确状态。外部连接器已有上游代码也要重新验证实际配置。

## V5-04｜字段与语义映射契约

- [ ] 文件：拟新增 E/`source_mapping.py`、T。明确主键/事实粒度/时间/时区/币种/状态/金额单位/分母；映射版本不可变。不同业务定义创建新指标 ID 或版本，不偷换现有指标含义。
- 验收：分与元、含税/运费、支付与商品金额、UTC 与源本地日期混淆均阻断或显式转换；缺成本/退款仍不启用相应业务指标。

## V5-05｜质量检查与导入暂存

- [ ] 文件：拟新增 E/`import_validation.py`、T。原始数据只写 staging，检查重复主键、空必填、负值语义、无效日期、FK、覆盖/完整性，生成可读报告；坏数据不能部分进入正式快照。
- 验收：合法/重复/空值/坏币种/模式错误 fixture 分别处理；未知状态不默认为 delivered；上传单元格的指令文本只当数据，不进入高权限系统提示词。

## V5-06｜不可变快照与发布事务

- [ ] 文件：现有 snapshot/evidence/task_store 适配，T。以源文件/读取批次、mapping_version、转换版本生成新 snapshot_id；校验通过后原子发布 active 指针，保留旧快照。
- 验收：导入中断不污染 active；相同输入幂等；旧节点仍指向旧数据，刷新不重算旧结果；不同来源的数据不能仅因字段相同而覆盖同 snapshot ID。

## V5-07｜增量与重复处理策略

- [ ] 仅源有可靠更新时间/主键时做增量；否则首版明确全量刷新。输出 watermark、upsert/delete 语义及回放规则，文件落在所选 connector/导入实现。
- 验收：重复批次、乱序更新、相同时间戳、删除事件、半批失败不重复计数；无法证明增量正确则保留全量方案并记录原因，不造 watermark。

## V5-08｜模式变化阻断

- [ ] 文件：mapping/quality 检查、T。识别删除列、类型变化、精度变化、状态新值；按明确兼容规则处理，加列是否允许必须有 schema 策略。
- 验收：不兼容变化进入 `schema_changed`/待重新映射；不静默补空继续执行；原 active 快照仍可用；重新映射产生新版本。

## V5-09｜刷新与失败回退

- [ ] 文件：导入任务与快照目录、T。刷新创建独立 task/run 和预算，覆盖连接→暂存→校验→发布各阶段；失败保留诊断且 active 不动。
- 验收：网络断开、超时、质量失败、磁盘不足、发布前进程死亡均回退；重复点击同幂等键不新导入；取消安全清理当前临时资源，不删用户旧快照。

## V5-10｜数据源与快照选择 UI

- [ ] 文件：F/新受限数据源组件、API、FT。展示来源、更新时间、观测覆盖/完整性、单位、mapping 版本和当前快照；旧节点展示其原快照；更新时不替用户切换已完成分析。
- 验收：无权限数据源不出现在列表；选择另一个币种/粒度时明确不可比；导入/刷新失败可解释；实现细节留在详情。

## V5-11｜新数据源代表任务与隔离回归

- [ ] 使用新源回答01中的代表问题并独立计算；按V2评测 schema增加样例。跨源比较只在币种、时间、状态、粒度均可比时允许，不自动混合汇率。
- 验收：原源和新源分别重现；未经授权用户不可读取 connector/config/snapshot/任务；只读、质量、重复刷新与旧节点全部回归；没有做跨源 Join 就明确不支持。
