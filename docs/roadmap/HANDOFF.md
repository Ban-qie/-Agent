# 单任务执行与交接模板

每完成一个任务，将下面的记录写到 `docs/verification/<ID>/handoff.md`，在对应阶段卡上更新状态。记录私有结果的文件不得移入公开摘要。未通过的任务保留未勾选状态，并写清下一步。

```markdown
# 任务 ID / 标题
- 状态：未开始 / 进行中 / 通过 / 阻塞 / N/A（原因）
- 前置任务与证据：
- 本次目标（一个行为）：
- 开始提交、已有未提交差异、实际输入文件 SHA-256：
- 涉及文件（已有/拟新增）：
- 请求/响应或领域契约变化：
- 正常样例与预期：
- 边界/失败样例与预期：
- 修改摘要与不兼容风险：
- 验收命令、退出码、通过/失败计数、证据路径：
- 实际模型调用：新增次数、已知费用、未知用量、预留、累计账目指纹：
- 首次失败和修复记录（不能只保留最后成功）：
- 当前提交/补丁与回退方式：
- 尚未验证：
- 下一任务 ID、第一步、所需输入：
```

任务太大时先追加两个更小任务卡：一张定义/实现纯函数或存储契约，一张接 API/页面。共享数据与权限设计不能凭模型猜测；先写可评审的 schema 和反例，再实施。涉及交易、对象授权、版本迁移的工作需要有真实行为测试；可逆文档/样式修改不必额外编写测试。
